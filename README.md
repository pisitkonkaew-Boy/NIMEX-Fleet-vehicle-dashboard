# NIMEX Fleet Vehicle Dashboard

เที่ยววิ่งรถร่วม ระยะทาง และเที่ยววิ่งปกติ / มีความเสี่ยง / ผิดปกติ ราย DC และรายทะเบียน หน้าตาตาม NIMEX Design Kit
หน้าเว็บอ่านข้อมูลจาก Google Sheet ผ่าน Apps Script — **repo นี้ไม่มีตัวเลขจริง** ห้ามนำ fv-seed.json หรือไฟล์ Excel ขึ้น repo

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| index.html | หน้าแดชบอร์ด (การคำนวณและการอ่านไฟล์ Excel เหมือนเดิมทุกอย่าง) |
| config.js | ที่อยู่ Apps Script (`FV_API`) และเลขเวอร์ชัน (`FV_V`) |
| boot.js | โหลดข้อมูลจาก Sheet, ตรวจรหัสผู้ดูแล, นำเข้าครั้งแรก, บันทึกไฟล์ที่อัปโหลด |
| Code.gs.txt | โค้ดฝั่ง Apps Script (แท็บ Rows / Log) |

## ติดตั้งครั้งแรก
1. สร้าง Google Sheet ใหม่ → Extensions > Apps Script → วางเนื้อหา `Code.gs.txt` บันทึกเป็น Code.gs
2. Project Settings > Script Properties → เพิ่ม `ADMIN_KEY` = รหัสผู้ดูแล
3. Deploy > New deployment > Web app > Execute as: **Me**, Who has access: **Anyone** → คัดลอก URL ที่ลงท้าย `/exec`
4. แก้ `config.js` ใส่ URL ที่ `FV_API` แล้วอัปโหลดไฟล์ทั้งหมดขึ้น repo
5. เปิดลิงก์เว็บต่อท้าย `#admin` → ใส่รหัส → หน้า "ตั้งค่าครั้งแรก" → เลือกไฟล์ `fv-seed.json` (หรือกด "อัปโหลด Excel แทน")

## อัปเดต Apps Script (เมื่อ Code.gs.txt เปลี่ยน)
วางเนื้อหา `Code.gs.txt` ทับ Code.gs เดิม → บันทึก → Deploy > Manage deployments > ✏️ แก้ไข > Version: **New version** > Deploy (ลิงก์ /exec เดิมใช้ต่อได้ ไม่ต้องแก้ config.js)

## ใช้งาน
- ผู้ชมทั่วไป: เปิดลิงก์ปกติ ดูได้อย่างเดียว ไม่เห็นปุ่มอัปโหลดและส่งออก
- ผู้ดูแล: เปิดลิงก์ต่อท้าย `#admin` → ปุ่ม 📁 → เลือกไฟล์ Excel → ระบบสรุปจำนวนเที่ยวและช่วงวันที่ให้ตรวจก่อนบันทึก
- อ่านได้ทั้งไฟล์ที่หัวตารางอยู่แถวแรก และไฟล์รายงาน **NIMEX026001** (มีชื่อรายงาน แถวชื่อ DC และแถวรวม — ระบบข้ามให้เอง)
- นับเฉพาะชนิดรถ 040 / 041 / 042 ที่ประเภทการปล่อยรถเป็น 02 / 03 / 05
- การอัปโหลด **รวมกับข้อมูลเดิม**: เลขที่ใบรายการซ้ำ → ใช้ค่าจากไฟล์ใหม่, เลขใหม่ → ต่อท้าย (ข้อมูลเดือนก่อนยังอยู่) แล้วคำนวณส่วนต่างไมล์ใหม่ทั้งชุด
- ส่วนต่างไมล์ **เทียบข้ามวันเท่านั้น** (ใบรายการวันเดียวกันไม่เทียบกัน): ไมล์ออกแรกสุดของวัน − ไมล์เข้าสูงสุดของวันล่าสุดที่รถวิ่ง → ติดลบ = ผิดปกติ · 0 = ปกติ · 1–10 กม. = เสี่ยง · เกิน 10 = ปกติ
- แถบบน: **ทั้งหมด / BKK / UPC** · **วัน / สัปดาห์ / เดือน** + ช่วงเวลา · Zone · DC · ตัวกรองเพิ่ม (ชนิดรถ/ทะเบียน/ประเภทเที่ยว) · โหมดมืด · แชร์ (ผู้ดูแล) — จับภาคจากตาราง `ZONE_MAP` ใน index.html (BKK = Zone BKK, ที่เหลือ = UPC)
- KPI มี ▲▼ เทียบช่วงก่อนหน้าที่มีวันทำงาน (จ.–ส.) เท่ากัน: วัน → วันเดียวกันสัปดาห์ก่อน · สัปดาห์ → สัปดาห์ก่อน · เดือน → N วันทำงานแรกของเดือนก่อน
- หน้า: ผู้บริหาร · ทีมงาน · เทรนด์ · **วิเคราะห์** (เลือกมิติ × ตัวชี้วัด เรียงแย่สุดก่อน คลิกดูรายละเอียด) · **รายการ** (ตารางเที่ยววิ่ง) · **ตั้งค่า** (ผู้ดูแล: เกณฑ์แจ้งเตือน, ทะเบียนยกเว้นแบบติ๊กเลือก, ตรวจเลขไมล์, จับภาค, ข้อมูล)
- คลิกจุดบนกราฟรายวัน → เปิดวันนั้น
- **แชร์และส่งออก** (ผู้ดูแล, `export.js`): เลือกหัวข้อ → Excel (ชีตละหัวข้อ + รายการเที่ยว), PowerPoint 16:9, รูปยาว PNG, อินโฟกราฟิก A4 2480×3508, ข้อความ LINE, ลิงก์ผู้ชม — ไฟล์ชื่อ `NIMEX-FleetVehicle-<ช่วง>.*`
- ลิงก์จำตัวกรองได้ เช่น `?g=BKK&m=month&p=2026-10`
- **ทะเบียนยกเว้น** (รถจอดที่สาขา): ผู้ดูแลเพิ่ม/ลบได้ในหน้า "เทรนด์" > กำหนด Alert Threshold — ส่วนต่าง 0–10 กม. ถือว่าปกติ บันทึกในแท็บ Exempt ของ Google Sheet มีผลทันทีไม่ต้องอัปโหลดใหม่
- ระยะทาง 0 หรือเกิน 1,000 กม. ใช้ค่าเฉลี่ยของทะเบียนแทน และแสดงในกล่อง "ตรวจเลขไมล์" (เห็นเฉพาะผู้ดูแล)
- แก้หน้าเว็บแล้วผู้ชมยังเห็นของเก่า ให้เพิ่มเลข `FV_V` ใน config.js

## แชร์ / ส่งออก / อินโฟกราฟิก 16:9 (ผู้ดูแล)
- ปุ่ม 📤 บนแถบบน (เห็นเฉพาะ `#admin`) → เลือกช่วง เดือน/สัปดาห์/วัน และภาค → อินโฟกราฟิก 16:9 (PNG 3840×2160), Excel (1 ชีตต่อหัวข้อ), PowerPoint, PNG ยาว, ข้อความสรุป
- ⚙️ ตั้งค่าเกรด / KPI: เกณฑ์เกรดจาก % เที่ยวปกติ, KPI ที่แสดง, เที่ยวขั้นต่ำของ DC — บันทึกลง Sheet (ต้องใช้ Code.gs รุ่น 2)
- ภาค = ตาราง DC→ภาค ชุดเดียวกับ Delivery Driver Performance
